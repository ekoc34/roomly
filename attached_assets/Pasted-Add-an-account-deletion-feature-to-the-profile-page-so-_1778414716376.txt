Add an account deletion feature to the profile page so users can permanently close their account. Do NOT add any account freezing or temporary deactivation options.

TASK 1 — Add "Account verwijderen" section to ProfilePage
1. Open ProfilePage.tsx and add a new danger zone section at the very bottom of the page.
2. Title: "Account verwijderen" with a warning icon (AlertTriangle from lucide-react).
3. Description text: "Je account permanent verwijderen. Deze actie kan niet ongedaan worden gemaakt. Al je gegevens worden definitief verwijderd volgens de AVG/GDPR richtlijnen."
4. Add a red/destructive styled button: "Account verwijderen" with bg-red-500 hover:bg-red-600 text-white.

TASK 2 — Create a confirmation modal
1. When the user clicks "Account verwijderen", open a modal with the following:
   - Title: "Weet je zeker dat je je account wilt verwijderen?"
   - Warning text: "Dit is permanent. Je verliest al je listings, berichten, favorieten, en verificaties. Deze actie kan NIET ongedaan worden gemaakt."
   - Two input fields: email confirmation (type in your email to confirm) and password (for re-authentication)
   - Two buttons: "Annuleren" (cancel, closes modal) and "Verwijder mijn account" (destructive red, disabled until email matches user's email AND password is filled)
   - The "Verwijder mijn account" button should show loading state while processing

TASK 3 — Handle account deletion
1. On confirm:
   a. Call supabase.auth.signInWithPassword with the user's email and password to re-authenticate.
   b. If re-authentication fails, show a toast: "Ongeldig wachtwoord. Probeer opnieuw."
   c. If re-authentication succeeds:
      - Delete the user's profile from the profiles table (this cascades to conversations, messages, applications, favorites, saved_searches, listing_views, listing_reports per the existing foreign key ON DELETE CASCADE constraints)
      - Mark listings as anonymous (set user_id to NULL or a deleted-user UUID) instead of deleting them, so existing conversations/transactions aren't broken for the other party
      - Call supabase.auth.admin.deleteUser if available, otherwise call a Supabase Edge Function to delete the auth user
      - Show a success toast: "Je account is definitief verwijderd."
      - Sign out the user and redirect to the homepage ("/")
   d. Handle any errors gracefully with a toast: "Er is iets misgegaan. Probeer het later opnieuw."

TASK 4 — Keep everything else intact
1. All text in Dutch.
2. Use existing Tailwind v4 styling (rounded-2xl, stone colors, existing modal patterns).
