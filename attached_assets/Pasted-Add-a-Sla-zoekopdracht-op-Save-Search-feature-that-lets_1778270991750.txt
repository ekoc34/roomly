Add a "Sla zoekopdracht op" (Save Search) feature that lets tenants save their current filters and get notified when a new matching listing is posted.

TASK 1 — Database Schema
Add a `saved_searches` table to schema.sql:
CREATE TABLE IF NOT EXISTS public.saved_searches (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
  name TEXT NOT NULL DEFAULT 'Mijn zoekopdracht',
  filters JSONB NOT NULL DEFAULT '{}',
  notify BOOLEAN NOT NULL DEFAULT TRUE,
  last_matched_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

ALTER TABLE public.saved_searches ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can manage their own saved searches"
  ON public.saved_searches FOR ALL
  USING (auth.uid() = user_id);

TASK 2 — UI Components
1. On the listings page (/kamers), add a "Sla zoekopdracht op" button 
   next to the existing filters or above the listing results.
2. When clicked, it saves the current URL search params (q, min, max, district, type, 
   pets_allowed, smoking_allowed, gender_preference, rooms, sort) as a JSON object 
   to the `saved_searches` table.
3. Show a toast: "Zoekopdracht opgeslagen!" on success.
4. Add a small bell toggle next to it to enable/disable notifications for this saved search.
5. If the search is already saved, show "Zoekopdracht verwijderen" instead.

TASK 3 — Saved Searches Page
1. Add a new page at /opgeslagen-zoekopdrachten accessible from the Dashboard 
   "Mijn zoektocht" tab or the main navigation.
2. List all saved searches with: name, filter summary (e.g., "Amsterdam, max €800, 2+ kamers"), 
   notification toggle, last matched date, and a delete button.
3. Clicking a saved search navigates to /kamers?{filters} with all the saved params applied.

TASK 4 — Notification Trigger
1. When a new listing is created (check NewListingPage or the Supabase insert), 
   check the `saved_searches` table for matching filters that have notify = TRUE.
2. For each matching saved search, insert a notification into the `notifications` table 
   with type = 'new_matching_listing', title = "Nieuwe woning gevonden!", 
   body = "Een nieuwe woning matcht met je opgeslagen zoekopdracht '[name]'."
3. The notification's related_id should point to the new listing so clicking it 
   navigates directly to /kamers/[id].

TASK 5 — Keep Dutch Labels
All user-facing text must be in Dutch: "Sla zoekopdracht op", "Zoekopdracht opgeslagen!", 
"Zoekopdracht verwijderen", "Opgeslagen zoekopdrachten", "Notificaties aan", "Notificaties uit", 
"Nieuwe woning gevonden!", "Een nieuwe woning matcht met je opgeslagen zoekopdracht".
