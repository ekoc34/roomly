- "E-mailadres zichtbaar voor anderen"
- "Telefoonnummer zichtbaar voor anderen"

These must be OFF by default for new registrations.

2. Ensure that when a profile is first created, `show_email` and `show_phone`

4. In the toggle component on ProfilePage, ensure the checked state 
   correctly reads from `profile.show_email` and `profile.show_phone` 
   and defaults to false when the value is null.
